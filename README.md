# MBH Date Spoofer

A simple Python tool to generate backdated Git commits and customize your GitHub contribution graph.

## Features
- Generate commits with custom dates
- Customize the number of contributions
- Lightweight and easy to use
- Written entirely in Python

## Installation

```bash
git clone https://github.com/xmbh/MBH-Date-Spoofer.git
cd MBH-Date-Spoofer
```

## Usage

```bash
python main.py
```

Follow the instructions in your terminal.

## Disclaimer

This project is intended for educational and experimental purposes. Generated contributions do not necessarily represent real development activity.
